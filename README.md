A free, open-source UI kit for .NET MAUI providing a set of controls and utilities for building modern cross-platform apps.

## Platform Support

| Platform | Minimum Version         |
| -------- | :---------------------: |
| iOS      | 14.0+                   |
| macOS    | 14.0+ (Mac Catalyst)    |

## Installation

Add the [NuGet package](https://www.nuget.org/packages/FreakyControls):

```
dotnet add package FreakyControls
```

Or via Package Manager Console:

```
Install-Package FreakyControls -Version xx.xx.xx
```

### Initialization

```csharp
using Maui.FreakyControls.Extensions;

public static class MauiProgram
{
    public static MauiApp CreateMauiApp()
    {
        var builder = MauiApp.CreateBuilder();
        builder
            .UseMauiApp<App>()
            .ConfigureFonts(fonts =>
            {
                fonts.AddFont("OpenSans-Regular.ttf", "OpenSansRegular");
                fonts.AddFont("OpenSans-Semibold.ttf", "OpenSansSemibold");
            });

        // useSkiaSharp: required for FreakyCheckbox, FreakyRadioButton, FreakySvgImageView
        // useFreakyEffects: required for touch/ripple effects
        builder.InitializeFreakyControls(useSkiaSharp: true, useFreakyEffects: true);

        return builder.Build();
    }
}
```

## Breaking Changes in v0.5.0+

The `Shared` folder was removed from all namespaces:

```csharp
using Maui.FreakyControls.Shared.Enums; // old
using Maui.FreakyControls.Enums;        // new
```

This applies to all sub-namespaces. Deprecated APIs from previous versions have also been removed.
